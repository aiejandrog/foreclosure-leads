# Miami-Dade Foreclosure Leads

Pending-foreclosure lead tracker for Miami-Dade County. Data: RealForeclose auction calendar + Property Appraiser public records.

Live tracker: https://aiejandrog.github.io/foreclosure-leads/

Call Mode (the phone page) is built once per caller, each with its own half of the dialable
list — the split is fixed at build time in `call_mode.CALL_SEATS`, so the same homeowner is
never on two phones:

- Alejandro: https://aiejandrog.github.io/foreclosure-leads/call/
- Carlos:    https://aiejandrog.github.io/foreclosure-leads/call/carlos/

Both are generated by the nightly and shipped by the existing `git add docs/call`.

Re-run: `run-leads.bat` (scrapes, scores, updates docs/index.html; push to update the site).
