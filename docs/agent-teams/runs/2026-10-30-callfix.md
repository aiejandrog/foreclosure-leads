## Findings for others (not fixed here)

- board owner / verifier: `_mergeLead` drops the after-the-yes unit and `replied` / `textopen` from a remote note on a lead the board already has. Suggested rule: take the unit (`nextStep`, `next`, `stageAt`, `equityVerified`, `keepOrSell`, `afterYesAt`, `apptUnverified`) from the side with the larger `afterYesAt`, never on a DNC/Dead lead, like `_merge_note` does.
- verifier (`_merge_note`): an incoming `no:'hard'` does not replace a stored `'soft'`; a second `wpe` address, a newer `wq` and `replied` are not taken. Suppression-surface fields, report only.
- bridge: `/refresh` and `/pid` need no key by design; `refresh_status.py` still uses a plain fetch for `/refresh`.
