# 2026-10-30 layout (callmode-dev, branch claude/agents-layout)

## Reproduction
Playwright + Chromium ran here. A Call Mode page from `call_mode.build_html` with invented rows (the
board lane, Find a number lane, a card, the red refresh banner painted in) was measured at 320, 360,
390, 430, 600, 768, 1024, 1280, 1440, 1920.
- Realistic data: NO width overflows on main. `scrollWidth == clientWidth` everywhere; `.wrap`, `.dfnav`
  (tab row), `.lane`, Find a number, Counts line all sit inside the column; the column is centred.
  Screenshot 1 (column shoved right and clipped) did NOT reproduce. Likeliest cause: a cropped or partly
  off-screen wide window, or a row whose content had no break point (below).
- Screenshot 2 is not a mystery: 700px = the 560px rule at 125% browser zoom (596 CSS px window).
- Real overflow found with hostile content: a 380-char unbroken token (e-mail/URL/run-together name) in
  the Find a number lane pushed the document 2081-3161px sideways at every width 320-1920 (flex/grid
  children will not shrink below an unbreakable word).
- Wasted space on main: 560px fixed from 640 to 1023px (73% of 768, 55% of 1023).
Screenshots (outside the repo): `%TEMP%\layout_{390,768,1440}_{before,after}.png`. 390 and 1440 are
pixel-identical before/after; 768 differs only inside the column (720px instead of 560px).

## OUTPUT-TEMPLATE
**What changed.** call_mode.py CSS only (block near .wrap): from 640px the column is `min(720px,100%)`
(was 560px), 880px from 1024px (unchanged), phones under 640px unchanged. `.wrap{min-width:0;overflow-wrap:anywhere}`
and `max-width:100%` on `.lane/.dfnav/.card` so an unbroken string wraps inside the column instead of
widening the page. No JS, ids or text changed.
**Tests run.** `python _calllayouttest.py` on unchanged main: 11 FAIL (Find a number lane overflow at every
width 320-1920, and 768 column 560 of 768 = 73% < 90%); after fix: all passed (10 widths x 2 views).
`_callwiringtest`, `_callequitytest`, `_afteryestest`, `_verifytraintest`, `_callnumlisttest`, `_lookuplanetest`: pass.
Full ci_suite: see below.
**Not run.** `_callmodetest.py` (needs the board twin in DEALFLOW_DIR). Real phone/iOS Safari rendering.
**Exposure.** Display only. Not the suppression surface; no send, stay or opt-out path.
