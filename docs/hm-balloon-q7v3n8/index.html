The honest limits — read before quoting anyone

× The exact MATURITY / balloon date is not in the recorded index. It lives inside the mortgage document image. Origin date is the proxy (hard-money = 1–2 yr balloon, exactly Jesse’s tell).
× LTV is against the county’s certified roll, not an appraisal. The roll is annual and trails the market, so these LTVs run CONSERVATIVE — a row at 85% may appraise inside the box. That is why 80–90% is labelled TIGHT rather than dead.
× 1701 of the 1770 zone loans carry no usable LTV. Either the LLC owns several parcels and the recorded index does not say which one secures the loan (read the mortgage), or no parcel sits in that LLC’s name today — usually because it already sold, which means they are not a refi client at all.
× Vacant-land rows are never scored. A ground-up construction loan is written against finished value; calling it “upside down” against dirt would be wrong on the first call.
